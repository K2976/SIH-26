# API Documentation — FitForge Backend

## Overview

The FitForge API is exposed over HTTP/JSON using Django REST Framework and documented via an OpenAPI 3.0 specification generated by `drf-spectacular`. All endpoints are rooted under `/api/v1/`.

Authentication is handled via JWT bearer tokens (`Authorization: Bearer <access_token>`), issued through `apps/accounts`.

---

## Active Endpoints

### 1. Authentication (`apps/accounts`)
- `POST /api/v1/auth/signup/`
  - **Auth**: AllowAny
  - **Body**: `{ "email": "string", "password": "string" }`
  - **Response (201)**: `{ "access": "jwt", "refresh": "jwt" }`
  - **Notes**: Automatically provisions `auth_user` with `username = email` and creates an empty `UserProfile`.
- `POST /api/v1/auth/login/`
  - **Auth**: AllowAny
  - **Body**: `{ "email": "string", "password": "string" }`
  - **Response (200)**: `{ "access": "jwt", "refresh": "jwt" }`
  - **Notes**: Validates credentials using email lookup.
- `POST /api/v1/auth/token/refresh/`
  - **Auth**: AllowAny
  - **Body**: `{ "refresh": "string" }`
  - **Response (200)**: `{ "access": "jwt", "refresh": "jwt" }` (Rotates refresh token).

### 2. User Profile & Preferences (`apps/accounts`)
- `GET /api/v1/profile/`
  - **Auth**: IsAuthenticated
  - **Response (200)**: UserProfile representation (biometrics, unit preference, timezone, activity level).
- `PATCH /api/v1/profile/`
  - **Auth**: IsAuthenticated
  - **Body**: Partial UserProfile fields.
- `GET, POST /api/v1/goal/`
  - **Auth**: IsAuthenticated
  - **Body (POST)**: `{ "energy_direction": "cut|maintain|gain", "training_focus": "strength|hypertrophy|endurance|general", "target_rate_kg_per_week": float, "auto_adjust": bool }`

### 3. Reference Library & System Config (`apps/reference`, `apps/api`)
- `GET /api/v1/app-config/`
  - **Auth**: AllowAny
  - **Response (200)**: `{ "min_supported_version": "1.0.0" }`
- `GET /api/v1/reference/manifest/`
  - **Auth**: IsAuthenticated
  - **Response (200)**: `{ "version": integer }` (Global reference version).
- `GET /api/v1/reference/exercises/?since=<version>`
  - **Auth**: IsAuthenticated
  - **Response (200)**: Array of updated exercises since version.

### 4. Planned Social Endpoints (`apps/social` — In-Flight)
- `GET, PATCH /api/v1/social/profile/me/`
  - Public profile handle, display name, bio, and avatar.
- `GET /api/v1/social/profile/<username>/`
  - Public profile lookup by handle.
- `POST /api/v1/social/follow/<username>/`
  - Follow/unfollow relationship.
- `GET, POST /api/v1/social/posts/`
  - Community feed & post creation (including shared workout highlights).
