# Monorepo Skeleton

Composed scope for a fully-specified greenfield scaffolding task: stand up
repo structure, build tooling, and CI without any product feature work.
Framing is cheap (intent-capture, scope-definition) since boundaries are
already pinned by the requester; practices-discovery affirms testing
conventions for a codebase with none yet; code-generation, build-and-test,
and ci-pipeline do the actual work. No design stages — there is no
structural ambiguity to design against on an empty repo.
